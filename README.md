## 👨‍💻 About Me

I'm a self-driven developer from Algeria who builds where the digital meets the physical. I specialize in the full stack — from clean, functional interfaces built on modern primitives like shadcn/ui, to bare-metal embedded systems logic running on microcontrollers in the field.

My foundation is in low-level systems and Rust, which instilled a "no-magic" approach to software. I don't just build apps; I build real-world products that ship — healthcare SaaS, driving school platforms, offline-first POS systems, fire detection models, and LoRa-based IoT infrastructure. I prioritize performance, maintainable architecture, and systems that don't break under pressure.

I also lead the **Pioneers CS Club** at my university and an **Aerospace & Astronomy Club** focused on rocket telemetry, drone search-and-rescue, and embedded hardware — bridging CS education with real engineering.

## 🏆 Featured Projects

### 🏥 MedLink — Healthcare SaaS (Algeria)
*Connecting doctors, patients, and pharmacies in one platform*

- Multi-tenant PostgreSQL schema with RLS and Algerian data protection law (Law 18-07/25-11) compliance
- Chargily Pay V2 integration (EDAHABIA / CIB) for Algerian payments
- BLAKE3 hardware fingerprinting for license enforcement + 30-day offline grace period
- Hono RPC backend hosted on DZSecurity (Algerian VPS) · Better Auth email verification

---

### 🚗 DriveTrack — Driving School Management Platform
*Full monorepo platform for driving school operations*

- Turborepo with Hono/Axum backend · React/TanStack Router web · Expo mobile · Tauri v2 desktop
- Stage-based student progression · AI quiz features · complete ERD & state machine specs
- Planned in a Linear workspace with 41+ structured issues

> [View repo →](https://github.com/ZAAFHachemrachid/DriveTrack)

---

### 🛒 Adrar Market POS — Offline-First Point of Sale
*Built for the Algerian market with zero-dependency local operation*

- Tauri v2 + SQLite local-first architecture with PostgreSQL cloud sync
- Outbox pattern for reliable sync · UUIDs everywhere · optimistic local stock
- Supports color+size clothing variants, weight-based products, and JSONB attribute modeling

- YOLOn for Jetson Nano (edge) · YOLOl for ground server — **92–96% mAP@50**
- Trained on D-Fire dataset, deployed as part of the Pioneers Club's AI Day research track
